# Jason C. Chang | Senior BI & Analytics Manager Portfolio

Interactive portfolio built with Streamlit, showcasing BI leadership across enterprise data platform architecture, cross-channel attribution, sales pipeline analytics, and profitability analysis.

**Live:** [jc-portfolio.streamlit.app](https://jc-portfolio.streamlit.app)

## Pages

- **Home** — positioning, proof metrics, flagship project, testimonial
- **Work** — 3 deep-dive case studies with dashboard screenshots
- **About** — career timeline, skills, certifications
- **Live Demo** — interactive profitability explorer (~$392M shipped sales, 76 accounts, 9 divisions)
- **Connect** — contact info, resume download

## Stack

- Python / Streamlit
- Pandas / Plotly
- Power BI (dashboard screenshots)
- SQL, Snowflake, DAX (referenced in case studies)
